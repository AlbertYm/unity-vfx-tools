# 特效贴图调整 1.1.0

将整个 `Editor` 文件夹复制到 Unity 工程的 `Assets` 下（可以放在自己的工具子目录）。等待编译后，打开顶部菜单 **Effect Tools → Texture Adjust → 贴图调整**。也可以在 Project 选中贴图，右键 **Effect Tools → 贴图调整**。

1. 选择贴图，点击“使用 Project 当前选中的贴图”，或拖到窗口的“源贴图”。切换源图会重置参数。
2. 调整角度；正值为顺时针。按钮支持左右旋转 90°、旋转 180°。
3. 开启“扩展画布”可保留完整旋转结果；关闭则保持原宽高，边缘可能被裁切。新露出的区域透明。
4. 根据需要勾选去色，调整明度、对比度、黑场、白场、中间调。
5. 点击“另存为新 PNG”，选择工程内的位置。已有同名文件自动加编号，不覆盖原图。不自动替换材质里的贴图。

## 参数

- 明度 / 曝光：0 不变，+1 将 RGB 乘 2，-1 乘 0.5；超过白色的部分会截断。
- 对比度：1 不变，大于 1 拉开明暗，小于 1 压缩明暗。
- 黑场：将低于该值的部分压黑。
- 白场：将达到该值的部分提白。
- 中间调：1 不变，大于 1 提亮中间层次，小于 1 压暗。
- 去色：将 RGB 转为加权灰度，保留原 Alpha。黑白场、中间调、明度和对比度同样不调整 Alpha。

处理顺序：旋转 → 去色（可选）→ 曝光 → 黑白场 → 中间调 → 对比度。参数针对图片 RGB 数值，不模拟 Photoshop 色彩管理。预览底色只用于观察，不写入图片。

## 图片与导入设置

PNG/JPG 直接读取原始文件，不受 Unity 压缩、Max Size 和 Read/Write 开关影响；其他格式读取 Unity 当前已导入像素，受导入尺寸和压缩影响。源文件及源图导入设置不变。

输出为 8 位 PNG 普通 Texture，保留源图的 sRGB、Alpha Is Transparency、Mip Maps、Wrap、Filter、Aniso 设置；默认无压缩、关闭 Read/Write、不缩放非二次幂尺寸。平台专属覆盖、Sprite 切片和 Atlas 设置不复制。使用前可根据项目规范调整新图的压缩与平台设置。

任意角度使用带透明权重的双线性采样，避免透明边缘混入隐藏颜色；90° 整数倍在适合的画布下直接映射像素。颜色操作保留 Alpha，旋转会重新采样 Alpha。扩展画布可能增大贴图及内存；单张输出上限 33,554,432 像素、单边 16,384。

只接受普通 Texture 或 Sprite，不接受标为 Normal Map、Lightmap 等类型的数据贴图。即使导入类型为 Default，也请勿将本工具用于法线、HDR 或有特殊数值含义的数据贴图。

预览最长边 640 像素；导出以完整读取尺寸重新处理。大图导出为同步操作，可能短暂等待。工具只在编辑器运行，不给运行时增加贴图旋转 Shader 或组件。

## 移除

删除安装的 `VFXTextureAdjust.cs` 即可移除菜单。导出的 PNG 是独立资源，继续可用；原图未被修改。

# 粒子按贴图批量命名

版本：1.0.0。Unity Editor 工具。

## 安装与使用

把本目录的 Editor 文件夹复制到 `Assets/EffectTools/texture-rename/`，等待编译。已有同名类时替换原脚本内容并保留原 .meta，勿重复安装。

- 预览入口：**Effect Tools → 粒子按贴图批量命名**。选中特效父节点或粒子，预览后点击“应用批量命名”；可包含未激活子层，也可指定贴图属性。
- 快捷入口：在 Hierarchy 多选粒子，右键 **粒子按贴图命名（仅所选）**，直接处理所选粒子，不弹窗、不递归未选中的子层。该命令也出现在 GameObject 菜单。
- 两种入口均支持 Ctrl+Z 一次撤销整批操作，完成后按正常流程保存场景或 Prefab。快捷操作结果写入 Console。

## 命名规则

读取第一份粒子材质，依次尝试 `_TextureSample0`、Shader 标记的主贴图、`_BaseMap`、`_MainTex`，最后按 Shader 顺序查找第一张已赋值资源贴图。窗口可指定属性覆盖自动识别；右键始终自动识别。不读取拖尾材质，也不按 Texture Sheet Animation 的 Sprite 名称命名。

按层级顺序生成 `贴图名`、`贴图名_1`、`贴图名_2`。批次内名称唯一，也避开未修改的同级节点；因此编号可能跳号。不同路径但同名的贴图同样顺延编号。无资源贴图时跳过；普通分组节点不改名。Project 中的 Prefab 应先进入 Prefab 编辑模式。

## 限制与验证

改名可能影响 Animation 路径和按名称查找的脚本，不会自动修复绑定。运行模式禁用改名。不修改贴图、材质或粒子参数。

2026-10-27：本机 Unity 2022.3.62f3 程序集独立编译通过；用户已确认原项目中预览窗口与右键批量命名好用。公开源码与验收版本功能一致。其他 Unity 版本、干净工程、全部渲染管线及独立撤销场景未完成验证；不同 Shader 的实际取图请先查看预览。

## 更新与回滚

更新前将原脚本备份到 Assets 外，保留原 .meta。回滚时恢复旧脚本；已发生的节点改名请通过 Undo 或场景/Prefab 备份恢复。卸载脚本不会自动恢复节点名。

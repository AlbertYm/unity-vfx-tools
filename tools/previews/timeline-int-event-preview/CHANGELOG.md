# 更新记录

## 1.0.2 — 2026-10-27

- 配置持久保存至本项目 UserSettings，使用稳定对象 ID 恢复场景对象、轨道和表情配置资产。
- 切换场景、关闭并重开窗口后保留多条配置、事件函数、恢复编号和折叠状态；恢复后不自动开始预览。
- 新增带确认的清空全部配置按钮；未加载场景引用不清空、不自动替换轨道。
- 原子替换写入并保留上一份备份；无变化不重复写盘，格式错误时保护原文件。
- 保留公开版通用配置与脱敏边界，无项目资源或固定业务配置。
- 编译及独立 Unity 持久化测试结果见同版本检查记录。

## 1.0.1 — 2026-10-27

- 菜单迁移至 Effect Tools → Timeline → Int Event Preview。
- 对比项目适配版本后，仅合入菜单路径变化；保留 TimelineFacePreviewConfig、Mesh / Renderer 匹配、可配置贴图属性与关键词，不引入项目资源路径和组件依赖。
- Unity 2022.3.62f3 程序集独立编译通过；本次未执行公开配置模式的 Unity 界面验收，历史验收边界不变。

## 1.0.0 — 2026-10-13

- 首次公开收录多轨道 Timeline Int 动画事件预览工具。
- 单窗口折叠配置、添加与移除条目、一键开启与停止，支持独立角色同步预览。
- 根据当前动画局部时间应用最近的有效 int 事件，支持跳转、回拖、片段裁剪、速度和循环。
- 支持现有 void 方法(int) 接收组件，以及不依赖运行时组件的临时材质表情预览。
- 公开版新增通用表情配置资产和按 Mesh / Renderer 名称查找，移除原项目的固定目录、角色命名、组件类型和 Shader 名称。
- 不包含项目 Prefab、贴图、材质、场景、原换脸脚本、内部路径或 Perforce 信息。
- 项目适配版已由用户验收；公开配置资产模式完成独立编译，尚未在 Unity 界面实测，详见 README。

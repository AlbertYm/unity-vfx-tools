## 本次整理检查（2026-09-27）

当前内容来自桌面脚本目录，9 个工具、12 个 C# 文件。原文件只读，分类副本保持源码字节一致；粒子编辑窗口由 Runtime 移到 Editor，未改算法。53 个来源文件全部归档，两个历史 JSON 的本机绝对路径脱敏，其他归档内容保持字节一致。

本次独立编译使用本机 Unity 2020.3.26f1c1 自带 Roslyn、Unity 引用程序集和 .NET Standard 2.0 参考程序集，语言版本 C# 7.3。检查包括每个工具独立编译、全部编辑器脚本一起编译、只包含 Runtime 的非编辑器编译，以及子弹时间旧计时分支。具体结果见 [本次检查结果](PUBLICATION_CHECKS.json)。

编译检查不会启动 Unity，也不是完整游戏构建或实际场景验收。新输入系统独占分支没有在本次重新编译。粒子编辑窗口能够编译不代表其输入处理、Undo 和 Prefab 保存可靠；这些限制见对应 README。

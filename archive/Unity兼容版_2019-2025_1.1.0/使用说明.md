# Unity 特效工具兼容包 1.1.0

兼容目标：Unity 2019.1–2019.4、2020.x、2021.x、2022.x、2023.x，以及 2024/2025 年发布的 Unity 6（6000.0–6000.3）。此范围是代码适配目标，不等于每个补丁版本、每种渲染管线都已实机验证。实测状态见《兼容检查结果.md》。采用 C# 7.3 以内语法，面向 .NET 4.x / .NET Standard 环境。

## 安装与更新

首次安装：将 `Editor` 和 `Runtime` 两个文件夹一起放进工程的 `Assets/EffectTools`。可只安装需要的工具；缩略图工具必须保留其三个文件，延迟播放必须同时保留 Helper 和 Runner。

已经装过旧版：替换对应的旧 `.cs` 内容，不要把相同脚本再放一份到另一目录。保留工程原有 `.meta`，避免场景/Prefab 丢失脚本引用。先备份旧 `.cs` 到工程外，回滚时覆盖回来即可。

`Blcak_Write.cs` 中原来的类名是 `ScreenColorControl`，`NewBehaviourScript.cs` 中原来的类名是 `EffectDelayHelper`。如果工程仍使用这两个旧文件名，请先在 Unity Project 窗口将它们重命名为 `ScreenColorControl.cs`、`EffectDelayHelper.cs`，让 Unity 保留原 GUID，再替换内容。不要让旧类与新类同时存在。

Editor 文件必须放在名为 `Editor` 的文件夹内，Runtime 文件不能放进 Editor。通常不需要创建 asmdef；如果放进自己已有的 asmdef，请确保编辑器程序集只编译 Editor 平台；启用新输入系统时，包含 ScreenColorControl 的程序集需引用 Unity.InputSystem。

## 工具入口与文件

| 功能 | 文件 | 使用位置 |
|---|---|---|
| 资源依赖与引用树 | Editor/DVClear.cs | Effect Tools → DV Clear |
| 特效预制体选帧缩略图 | Editor/VFXPrefabThumbnailWindow.cs、VFXThumbnailPreview.cs、VFXThumbnailStore.cs | Effect Tools → Prefab Thumbnail → 设置特效缩略图 |
| 贴图旋转、去色、明暗调整 | Editor/VFXTextureAdjust.cs | Effect Tools → Texture Adjust → 贴图调整 |
| 按贴图名称重命名材质 | Editor/ChangeName.cs | Unity Tool → Material Rename |
| 引用搜索 | Editor/FindReference.cs | Unity Tool → Reference Checker |
| 子弹时间 | Runtime/BulletTimeController.cs | 挂到 GameObject，在 Play 模式触发 |
| 特效延迟播放 | Runtime/EffectDelayHelper.cs、EffectDelayRunner.cs | Helper 挂到特效；Runner 自动创建 |
| 空格切换相机背景 | Runtime/ScreenColorControl.cs | 挂到 GameObject，场景需有 MainCamera |

贴图工具和缩略图工具仍提供 Project 右键入口。详细操作见 Docs 中的对应说明。

## 本次兼容修改

- 子弹时间按编译版本选择计时 API：Unity 2020.2+ 使用 double 计时，较旧版本使用 realtimeSinceStartup。旧分支长时间连续运行后的计时精度受 float 限制。
- DV Clear 不再访问早期 Unity 2019 中仍为 internal 的 EditorStyles.linkLabel，改用公开的 label 样式，保留点击定位行为。
- 布局间距统一使用长期可用的 GUILayout.Space，避免依赖 EditorGUILayout.Space 的版本相关重载。
- 背景切换根据工程输入后端选择旧 Input Manager 或新 Input System；无需为了本脚本改变工程输入后端。
- 预制体预览使用 EndPreview 返回的纹理，并在 BeginPreview 之后设置相机背景，避免不同编辑器内部初始化覆盖选定背景。
- 所有编辑器代码保留 UNITY_EDITOR 隔离；运行时脚本不引用 UnityEditor。
- 贴图工具经接口检查未发现需要替换的 2022 专用 API，因此保持原有像素处理逻辑。

## 适用边界

编译兼容不代表所有项目的特效内容都能完全还原。预制体缩略图预览主要支持内置 ParticleSystem 和常见 Renderer；它不会执行项目自定义脚本，不完整模拟 VFX Graph、UI、项目自定义渲染功能或依赖游戏逻辑触发的效果。URP/HDRP 可以走公开的预览渲染入口，但不同管线包和自定义 Shader 的实际画面未完成矩阵验证；不支持的内容可使用窗口内“指定 PNG”。

背景切换修改相机 backgroundColor，要求相机及管线实际使用纯色背景；Skybox 或 HDRP 的独立环境背景设置可能覆盖该颜色。

贴图颜色调整面向普通颜色图，输出 8 位 PNG；法线、HDR、特殊数据贴图不在范围内。非 PNG/JPG 格式使用 Unity 导入后的像素；扩展画布可能产生更大的图片。各版本的导入尺寸、GPU 上限及平台压缩规则仍由工程决定。

本包不会安装或更换 URP/HDRP/Input System，不修改项目全局设置。使用者应保留 Unity 标准的粒子、动画、IMGUI、ImageConversion 等所需内置模块。

## 备份与恢复

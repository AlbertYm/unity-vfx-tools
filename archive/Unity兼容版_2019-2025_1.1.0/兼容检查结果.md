## 实际 Unity 执行

Unity 2022.3.62f3 在独立测试工程运行并通过：

- 贴图恒等处理保留 RGBA、90° 顺时针映射、扩展和固定画布尺寸。
- 去色和明暗操作保留 Alpha，透明边缘使用带 Alpha 权重的采样。
- PNG 原始像素读取、PNG 编码，以及非 Read/Write TGA 的 GPU 回读。
- 上述读取前后源图 .meta 内容不变。
- 粒子选帧、固定种子反向跳帧重现、512×512 图像生成。
- 缩略图保存、重载、备份、Prefab 改名后按 GUID 关联、恢复默认时保留备份。
- 原 Prefab 和材质内容不变；5 个编辑器窗口类型实例化及清理。

已查看生成的粒子 PNG，包含有效粒子和背景。以上为 Built-in 管线的自动测试，不是用户实际工程中的鼠标交互或 URP/HDRP 视觉验收。

Unity 2020.3.26f1 和 2020.3.26f1c1 均尝试启动同类测试，但在执行前被本机许可证状态阻止，日志为 `Unity has not been activated with a valid License`。未修改许可证、Hub 或全局配置。因此这两者只有程序集编译证据，不能记为运行通过。

本机没有找到 Unity 2019、2021、2023、6000.x 安装，未在这些编辑器实际编译或运行。未安装额外 Unity 版本。

## 公开接口核对

- [Unity 2019.1 EditorStyles 源码](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Editor/Mono/GUI/EditorStyles.cs)：linkLabel 为 internal，已移除依赖。
- [Unity 2019.1 Time 源码](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Runtime/Export/Time/Time.bindings.cs)及 [2020.2 double 计时文档](https://docs.unity3d.com/2020.2/Documentation/ScriptReference/Time-realtimeSinceStartupAsDouble.html)：按版本编译计时分支。
- [Unity 2019.1 PreviewRenderUtility](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Editor/Mono/Inspector/PreviewRenderUtility.cs)及 [6000.3 同接口](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.3/Editor/Mono/Inspector/PreviewRenderUtility.cs)：使用公开的 BeginPreview、Render(bool,bool)、EndPreview、Cleanup。
- [Unity 2019.1 EditorUtility](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Editor/Mono/EditorUtility.cs)：确认 SaveFilePanelInProject 五参数重载。
- [Unity 2019.1 TextureImporter](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Editor/Mono/AssetPipeline/TextureImporter.bindings.cs)：核对贴图导入属性。
- [Unity 2019.1 粒子模块](https://github.com/Unity-Technologies/UnityCsReference/blob/2019.1/Modules/ParticleSystem/ScriptBindings/ParticleSystemModules.bindings.cs)：核对 useUnscaledTime、cullingMode 等。
- [Unity 2019.1 C# 编译器](https://docs.unity3d.com/2019.1/Documentation/Manual/CSharpCompiler.html)：按 C# 7.3 语法基线检查。
- [Input System 迁移说明](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.0/manual/Migration.html)：使用 ENABLE_INPUT_SYSTEM / ENABLE_LEGACY_INPUT_MANAGER 判断后端。

上述是针对关键差异的接口审查，不是每一个 Unity 小版本的完整 API 自动比较，也不能替代 2019/Unity 6 的编辑器验收。

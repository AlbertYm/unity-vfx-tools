# Unity 常用脚本修改版 · 2026-09-25

这是供工程内验证的源码副本。原件保留在上一级目录，未修改 G 盘工程。
本机 Unity 2022.3.62f3 程序集的编辑器条件与非编辑器条件独立编译已通过；尚未运行目标工程、验证场景或执行实际 Player 构建。

## 变更
- BulletTimeController：移除 ExecuteAlways；一次触发结束后自动取消开关；取消、禁用或销毁时恢复触发前时间；物理步长按原值同比缩放；阻止多个本工具实例同时接管时间。slowMagnitude 现在表示相对于触发前速度的倍率。
- EffectDelayHelper：替代 NewBehaviourScript.cs，保留原类名、命名空间和序列化字段；用新增 EffectDelayRunner 独立计时，防止自身关闭后协程停止。计时受 timeScale 影响。保留旧版目标帧率 60 和未使用字段 totalTime。
- ScreenColorControl：将 Blcak_Write.cs 改为与组件类匹配的文件名；背景切换逻辑未改。
- DVClear：增加正反向统计含义和扫描范围提示；将“只看未引用”改为“只看扫描结果为 0”。未扩大扫描范围，未改变删除机制。
- DVClear、ChangeName、FindReference：增加 UNITY_EDITOR 条件，避免玩家程序集引用 UnityEditor。后两个工具的业务逻辑未改。
- 六份原有 .meta 完整保留；EffectDelayRunner 使用新 GUID。

## 放回工程
不要把整个修改版文件夹拖进已有工程，与旧脚本并存会产生重复类或重复 GUID。
1. 先备份目标工程中准备替换的 .cs 和 .meta（放在 Assets 外）。退出 Play 模式。
2. 在 Unity Project 窗口把 Blcak_Write.cs 重命名为 ScreenColorControl.cs，把 NewBehaviourScript.cs 重命名为 EffectDelayHelper.cs。这一步保留目标工程自己的 .meta 和引用。
3. 将本目录的六份对应 .cs 覆盖到工程中的原位置，仅替换代码，保留工程现有 .meta。若工程不存在该脚本，则先检查是否有同名类，再作为新脚本导入。
4. EffectDelayHelper.cs 同目录新增 EffectDelayRunner.cs 及其 .meta。这两个运行时脚本不要放在 Editor 文件夹内。
5. 不要把说明、原件校验 JSON 或上一级旧脚本再导入 Assets。

## 建议验证
- Console：等待 Unity 编译完成，确认无报错，场景与 Prefab 的组件不出现 Missing Script。
- 慢动作：Play 模式设倍率 0.1、持续 2 秒；勾选后只播放一次并自动取消。中途取消、关闭组件或关闭物体，确认时间恢复；连续重新触发也应正常。多个实例同时触发时仅一个接管。
- 延迟：delay 设 1 秒，确认特效先隐藏再显示；显示后勾选 replay，确认再次延迟显示；等待期间关闭父物体，再开启父物体，应重新开始延迟。检查场景卸载后没有残留辅助对象。
- 黑白背景：相机使用纯色背景（Built-in Clear Flags 为 Solid Color），运行时按空格测试。
- DV Clear：检查菜单、扫描、引用树展开和说明提示。0 仅表示已扫描范围的统计结果；动态加载与其他资源类型并未覆盖。

## 限制与回滚
- 以上运行行为仍待实际工程验证；独立编译不证明场景挂载、Prefab 引用或播放正确。
- 慢动作控制的是全局 Time；工程中其他时间管理器仍可能与之冲突。
- 延迟对象隐藏期间自身 Update 不运行；重播开关在显示后使用。等待由同场景隐藏辅助对象执行。
- DV Clear 仍使用永久删除，不能 Undo；本轮未实际删除任何工程资源。
- 回滚：还原备份代码；在 Unity 中把两份改名文件改回旧名，保持原 .meta；移除本轮新增的 EffectDelayRunner.cs 及其 .meta。不要把备份作为第二套脚本放回 Assets。

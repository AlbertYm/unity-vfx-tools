# 特效 Prefab 选帧缩略图 · 1.0.0

用途：把 Unity Project 窗口中 Prefab 的蓝色方块，替换成你选择的特效画面。每个 Prefab 可以保存不同的时间、视角和背景。

## 安装（一次即可）

1. 将本目录中的整个 `Editor` 文件夹，复制到项目的 `Assets/VFXPrefabThumbnail/Editor`。
2. 等待 Unity 编译完成。不要把同一套脚本放进项目两次。
3. 不需要把脚本挂到 GameObject，也不需要修改 Prefab。

脚本以 Unity 2022.3 为基准，使用公开 Editor API，并有 UNITY_EDITOR 条件保护；其他 Unity 版本未实测。

## 为一个特效挑选缩略图

1. 在 Project 中选中一个 `.prefab` 文件。
2. 右键选择 `Effect Tools → 设置特效缩略图`。也可从顶部菜单 `Effect Tools → Prefab Thumbnail → 设置特效缩略图` 打开窗口。
3. 点击播放或拖动时间轴，找到最能代表该特效的时刻。例如爆点展开后的 0.3 秒。
4. 左键拖动画面旋转视角，右键拖动平移，滚轮缩放。看不到效果时先拖到非零时间，再点“适配画面”。
5. 点击“保存当前帧为缩略图”。回到 Project，蓝色方块位置会显示刚保存的画面。
6. 拉大 Project 右下角的图标大小滑杆，便于辨认。小列表视图也会绘制 16 像素缩略图，但细节较少。

窗口中方形预览区域就是保存时的构图。支持前后逐帧、输入采样帧、24/30/60 FPS、固定随机种子、背景颜色、正交视角；预览范围可设为 0.1～30 秒。这里 FPS 是采样步长，不是自动识别的源动画帧率。

“跟随 Project 选择”默认开启，便于连续处理不同 Prefab；切换前记得保存当前画面。播放、拖动与调整视角本身不会自动覆盖已保存缩略图。

## 不依赖自动模拟的另一种方式

如果某个特效必须由游戏逻辑、插件、特殊 Shader 或 VFX Graph 驱动，可先在自己的正常工作流程中截图，再在本窗口点“指定 PNG”。

建议使用方形图片，边长不超过 2048 像素、文件不超过 16 MB。非方形图片会等比例放入图标区域。此功能同样以 Prefab GUID 对应图片，不需要更改 Prefab。

## 保存位置与原素材保护

- 缩略图 PNG 和取帧参数保存在当前 Unity 项目的 `UserSettings/VFXPrefabThumbnails`。
- 按 Prefab GUID 关联，因此在 Unity 中改名、移动路径后，只要原 `.meta` GUID 保持不变，缩略图仍可对应。
- 关闭或重启 Unity 后重新载入。清理 Library 不会清除本工具保存在 UserSettings 下的图片。
- 本工具只在 Project 图标位置绘制图片，不修改 Unity 内部的 AssetPreview，也不改变其他工具获取到的缩略图或 Inspector 默认预览。
- 不改写 Prefab、材质或原始贴图，不添加组件，不会把缩略图打进游戏包。
- 覆盖保存时，上一版图片/参数保留为 `.previous`。恢复默认时，现有图片和参数移动到数据目录的 `Backups` 子目录。
- 默认是本机、本项目的显示设置。如果需要同事也看见，需要在双方安装脚本，并复制对应数据目录；双方资源 GUID 必须一致。本脚本不会自动提交 Perforce/Git。

## 支持范围

- 预览器建立独立 Preview Scene，只复制内置可视组件：常规 ParticleSystem、网格、蒙皮网格、Sprite、LineRenderer、TrailRenderer。
- 不实例化自定义 MonoBehaviour，所以不会为了截图执行 Prefab 上的游戏脚本。被忽略的脚本数量会在窗口提示。
- 可选 AnimationClip 用于采样模型/骨骼及相关动画曲线，不自动运行 Animator Controller 状态机。
- 粒子使用固定随机种子，从起点重建指定时间；固定种子只作用于预览副本，不修改原件。
- 已启用当前 SRP 渲染路径，便于 URP/HDRP 项目使用，但目标项目的自定义 Renderer Feature、后处理、灯光环境未完整复现，也未在你的 TD 项目中实际运行。
- 不保证还原依赖脚本启动、碰撞、运行时材质参数、Shader 全局时间、相机深度、主场景灯光、VFX Graph、Spine 或 UI Canvas 的效果。TrailRenderer 的完整运动轨迹也不保证恢复。此类资源可用指定 PNG 方式。
- 空白图不一定代表 Prefab 无效：先检查时间、视角、根节点/子节点激活状态、粒子延迟以及上面的支持范围。

## 更新与恢复

- Project 未立即更新时，用菜单 `Effect Tools → Prefab Thumbnail → 刷新缩略图显示`。
- 恢复某个 Prefab 的蓝色图标：在取帧窗口点击“恢复 Unity 默认图标（保留备份）”。
- 临时关闭整套功能：将这三个编辑器脚本移到 Assets 外，等待编译。Unity 会恢复原本的显示，数据仍保留。
- 数据目录可通过菜单 `打开缩略图数据目录` 找到。需撤回最近一次保存时，关闭 Unity，将当前 PNG/JSON 另存，再将对应 `.previous` 文件复制回原名。

## 本次验证

2026-09-26，Unity 2022.3.62f3：脚本程序集编译通过；独立 Built-in 测试工程中真实粒子模拟/512×512 截图、随机结果重现、图片与参数重新加载、GUID 改名关联、覆盖备份和恢复默认已通过。生成缩略图前后，测试 Prefab 与材质内容保持一致。

Project 图标绘制区域做了矩形边界检查；尚未在你截图中的 TD 项目人工点击验收，也未验证该项目全部特效和自定义渲染管线。建议先对一个常规粒子 Prefab 保存缩略图，确认取帧与 Project 显示符合预期，再继续处理其他资源。
